# Web 界面导览

Web 工作台基于 React、TypeScript 与 ECharts，由 `mqde serve` 托管，界面以中文呈现。以下截图来自包含已完成作业的运行实例。

左侧边栏把页面分组：*评估前*（部署预评估、模型结构、资源预估）、*量化与评测*（新建作业、作业与执行、配方对比）和*部署*（硬件与后端、模型目录）。底部有深色/浅色主题切换。

## 部署预评估

路由 `/fit`。目标系统面板（硬件画像、GPU 数量、系统内存、并发、上下文、用途）驱动一张按模型库排序的表：参数量、适配等级（完美 / 良好 / 勉强 / 太紧）、运行模式、最佳量化、显存、速度和评分。选中一行会显示评分构成（质量、速度、适配、上下文）、关键指标和跨硬件规划。这就是带图形界面的 `mqde fit`，见 [预估](estimate.md)。

```{figure} ../../_shared/img/fit.png
:alt: 部署预评估页
:width: 100%

部署预评估页：上方是目标系统，中间是模型排名，下方是评分构成与跨硬件规划。
```

## 模型结构

路由 `/graph`。类 netron 的浏览器：组件、块、模块、张量。节点颜色表示算子类型；点击节点可以看到它的张量、数值直方图和针对所选配方的量化误差预览。支持本地模型和 Hub 模型（只读头部，不下载权重）。

```{figure} ../../_shared/img/graph.png

一个视觉-语言-动作模型的结构：左侧是层级树，中间是单个块的前向图，右侧是属性面板。
```

## 新建作业

路由 `/new` 是全流程作业。LLM 另外有两个独立入口：

- `/new/quantize`：只量化并导出，常用参数是“主配方 → 可选的对比配方 → 量化算法 → 校准数据 → 导出格式”，高级参数折叠；
- `/new/eval`：只评测已有量化 checkpoint，页面只有“评测对象 → 评测数据集 → 可选部署”，数据集通过“套件 / 类别 / 数据集”下拉列表逐级选择。

全流程页面仍然保留模型类型、配方、算法、评估数据和目标硬件。LLM 的静态激活、KV Cache 量化、混合精度、llama.cpp 类型和敏感度分析在“高级”里。底部的 **JobSpec 预览**就是“提交作业”会 POST 到 `POST /api/v1/jobs` 的 JSON，即与[作业配置](job_spec.md)中的 JSON 结构一致。

```{figure} ../../_shared/img/ui-new-eval.png
仅评测作业：checkpoint、数据集和运行参数分块展示，部署与高级选项默认折叠。
```

## 作业列表与作业页

路由 `/jobs` 列出 `--runs` 目录中的所有作业（包括从命令行启动的），显示作业模式（全流程 / 仅量化 / 仅评测 / 部署评测）、状态、当前阶段、进度、配方、设备和耗时。整行可点击进入详情。

```{figure} ../../_shared/img/ui-jobs.png
:alt: 作业列表
:width: 100%

作业列表：运行中的作业显示当前阶段和进度条；顶部可直接新建全流程、仅量化或仅评测作业。
```

作业页（`/jobs/<job-id>`）从上到下包括：

- **作业头**：状态、模式、设备、阶段完成数、耗时、进度环，以及取消、下载日志、打开中英文 HTML 报告等操作；
- **运行监控**：当前阶段、进度、最近指标、耗时，以及带“全部 / 指标 / 错误”筛选、跟随最新、复制和下载的日志面板；
- **执行过程**（阶段流水线，按状态着色，带耗时和重复次数）与由事件流驱动的**实时日志**；
- 摘要卡片：基线 PPL、评估 token 数、校准窗口、模型块数与线性层数；
- 标签页：**总览**，以及每个配方一个**误差分析**页（按块和层类型的逐层误差热力图（SQNR dB）、各块平均 SQNR、误差对激活峰度、误差最大的 15 层，以及敏感度结果和“按建议生成新作业”按钮）；
- 三个评估位点的 **PPL 图**，以及**配方汇总**（算法、规格、PPL、相对原模型的变化、KV 增量、量化/跳过的层数、耗时、最差层）；
- **真实低比特导出与一致性校验**表；
- **vLLM / SGLang 部署与部署后精度**表，和/或 **llama.cpp 部署**图表。

## 硬件与后端、模型目录

`/hardware` 顶部是推理后端环境卡片（vLLM / SGLang / llama.cpp 的版本与安装状态），下面是：

- 目标设备探针卡片：设备名、厂商、arch、FlagTree target、计算单元、驱动、内存使用率；
- 算力能力折线图：按精度查看峰值 TFLOPS，支持显示具体数值；
- HAL 插件卡片与微基准；
- 按边缘 / 工作站 / 数据中心分组的硬件画像。

`/catalog` 提供本地模型、HF 模型目录，以及 HuggingFace / ModelScope 在线搜索和下载。下载器支持预算过滤、权重组选择和断点续传（服务器需要网络，主机没有网络时需要代理）。

```{figure} ../../_shared/img/ui-hardware.png

硬件与后端：顶部推理后端卡片，下面是部署目标卡片、探针设备、算力折线图和分组硬件画像。
```
